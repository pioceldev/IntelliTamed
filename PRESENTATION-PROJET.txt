-------------------------------------------------------------------------------
1. LE PITCH (à retenir en 30 secondes)
-------------------------------------------------------------------------------
IntelliTamed est une plateforme qui utilise l'intelligence artificielle pour
accompagner les entrepreneurs, créateurs de projets, freelances et
professionnels, de l'idée jusqu'au lancement de leur entreprise.

L'utilisateur discute avec un assistant IA qui connaît SES projets, SES
activités et SON profil, et qui est capable non seulement de conseiller, mais
aussi d'EXÉCUTER des actions réelles sur la plateforme : créer un projet,
lancer une analyse de marché, générer un plan d'action ou trouver des
opportunités personnalisées. Tout se fait par la conversation.

En clair : au lieu d'utiliser dix outils (Excel, Google, consultants...),
l'entrepreneur a un seul copilote IA qui fait le travail avec lui.

-------------------------------------------------------------------------------
2. LE PROBLÈME
-------------------------------------------------------------------------------
Créer une entreprise est complexe et risqué :

  * 90 % des startups échouent, souvent par manque de validation du marché.
  * Les entrepreneurs se noient : études de marché, business model, pricing,
    plan d'action, recherche de financement, opportunités... énormément de
    tâches à faire, aucune vue d'ensemble.
  * Les conseils sont chers (consultants) ou génériques (contenus en ligne).
  * Les outils d'IA classiques (chatbots) répondent de façon impersonnelle :
    ils ne connaissent ni les projets ni la situation de l'utilisateur.

-------------------------------------------------------------------------------
3. LA SOLUTION : UN CO-PILOTE IA QUI CONNAÎT L'UTILISATEUR
-------------------------------------------------------------------------------
IntelliTamed combine trois briques :

  1) UN ASSISTANT IA « MÉMOIRE »
     L'assistant a accès, à chaque message, au contexte réel de l'utilisateur :
     son profil (domaine, compétences, expérience), ses projets (nom, statut,
     progression), son plan d'action en cours et son activité récente.
     Résultat : il répond en connaissance de cause. Exemple réel :
       - Utilisateur : « Quels sont mes projets ? »
       - Assistant : « Vous avez 1 projet : Marketplace Freelances Créatifs
         (statut : Idée, progression 25%, catégorie Tech). Action prioritaire :
         valider le besoin côté acheteurs B2B avec 10 à 15 interviews. »
     Fini le « aucun projet existant » : l'IA voit réellement les données.

  2) UN ASSISTANT QUI EXÉCUTE (commandes)
     L'utilisateur peut « commander » l'IA en langage naturel pour agir sur le
     site :
       - « Crée un projet appelé Marketplace B2B »  → le projet est créé.
       - « Analyse mon projet X »                    → l'analyse IA est lancée.
       - « Génère le plan d'action de mon projet X » → le plan est généré.
       - « Génère des opportunités »                 → des opportunités
         personnalisées sont créées.
     L'IA confirme l'action dans le chat et donne le lien vers l'espace
     concerné (Mes Projets, Plan d'action, Opportunités...).

  3) UN ÉCOSYSTÈME COMPLET D'OUTILS
     - Tableau de bord : vue d'ensemble des projets, statistiques, activité.
     - Gestion de projets : phases, statuts, progression.
     - Analyses prédictives IA : forces, faiblesses, opportunités, risques,
       recommandations (rapport structuré par projet).
     - Plans d'action : étapes concrètes générées par l'IA, organisées en
       4 phases (validation, architecture, développement, lancement).
     - Opportunités dynamiques : le bouton « Générer mes opportunités IA »
       crée des opportunités adaptées au profil ET aux projets de l'utilisateur
       (financements, incubateurs, hackathons, partenariats, missions...).
       Chaque opportunité a un score de compatibilité expliqué.
     - Objectifs, notifications, profil/paramètres (sécurité, facturation,
       préférences), administration (pour les équipes).

-------------------------------------------------------------------------------
4. COMMENT ÇA MARCHE POUR L'UTILISATEUR (parcours)
-------------------------------------------------------------------------------
  1. Inscription (email ou Google/GitHub) → espace personnel.
  2. Onboarding : profil (type, domaine, compétences, expérience) — c'est ce
     qui permet à l'IA de personnaliser ses réponses.
  3. Création d'un premier projet (manuellement ou en le demandant à l'IA).
  4. L'utilisateur discute avec l'assistant : validation d'idée, stratégie,
     questions... l'IA répond avec le contexte de ses projets.
  5. À tout moment, il peut commander : analyse IA, plan d'action,
     opportunités, nouveau projet.
  6. Le tout est suivi dans le tableau de bord, avec notifications.

-------------------------------------------------------------------------------
5. L'INTELLIGENCE ARTIFICIELLE EN DÉTAIL
-------------------------------------------------------------------------------
  * Modèle : Google Gemini (clé API côté serveur uniquement — jamais exposée).
  * Contexte utilisateur : profil + projets + plan d'action + activité récente
    injectés à chaque demande (assistant, analyses, plans d'action).
  * Mémoire : les conversations sont conservées et rejouées dans le contexte.
  * Robustesse : si le modèle principal est saturé ou lent, bascule
    automatique sur des modèles de secours ; erreurs propres et compréhensibles.
  * Sécurité : aucun contenu simulé ; chaque réponse provient réellement de
    l'IA. Les données personnelles restent côté serveur.

-------------------------------------------------------------------------------
9. APERÇU TECHNIQUE (pour les curieux)
-------------------------------------------------------------------------------
  * Frontend : pages HTML/CSS/JavaScript (interface 100 % dynamique, aucune
    donnée fictive — tout vient de l'API).
  * Backend : Django + Django REST Framework (API sécurisée par JWT).
  * Base de données : MySQL (ou PostgreSQL/SQLite en développement), en
    UTF-8 complet (utf8mb4) pour gérer emojis et accents.
  * IA : API Google Gemini côté serveur, avec modèles de secours.
  * Emails transactionnels : Brevo (bienvenue, réinitialisation de mot de passe).
  * Connexion sociale : Google et GitHub (OAuth2).

-------------------------------------------------------------------------------
10. LANCER LE PROJET EN LOCAL (résumé)
-------------------------------------------------------------------------------
  1. cd backend
  2. Créer un environnement virtuel Python et installer requirements.txt.
  3. Copier .env.example vers .env et renseigner :
       SECRET_KEY, DATABASE_URL, GEMINI_API_KEY (obligatoire pour l'IA),
       éventuellement BREVO_API_KEY et identifiants OAuth.
  4. python manage.py migrate   (crée la base + tables)
  5. python manage.py createsuperuser
  6. python manage.py runserver
  7. Ouvrir http://127.0.0.1:8000/ — le serveur sert le site ET l'API.
